# 彰化發送運行看板 run-board

彰化(4106)＋秀水(4150)發送運行表分析網站。資料來源：HCT 報表平台【運務】拆封櫃明細查詢(RPT79)。

- 網站：https://ares-1215.github.io/run-board/ （工號＋密碼登入，可自行改密碼）
- 後端：Supabase Edge Function `runsheet`＋資料表 `rs_legs`／`rs_users`（RLS 全鎖，僅走 Edge Function）
- 更新：`python tools/fetch_runsheet.py`（預設抓昨天；`--from/--to` 回填區間）
  - `tools/config.local.json`（不入庫）：`edge_url`＋`ingest_token`

## 班次分類
| 類別 | 判定 |
|---|---|
| 正班 | 其餘 |
| 加班 | 作業類別=加班車（彰化自行加開） |
| 增開 | 班次名稱含「增開」（運務處臨時增開） |
| 追加 | 作業類別=追加 |
| 過路 | 作業類別空白（＋秀過路加掛） |
| 取消 | 櫃號欄=「取消」，獨立統計 |

## 分析注意
- 同一班次會以「路順」分段出現在彰化與秀水兩邊查詢，入庫保留段級，網站端以 日期＋班次＋類別 去重計班次數。
- 過路(＋秀)車的「規定離站」多為原始起點表定時間，延誤統計一律排除。
- 準點定義：實際離站延誤 5 分內。營運日以中午 12:00 為分界處理跨夜。
